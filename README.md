# Site academic

Profil academic: cercetare doctorală, publicații, experiență și contact.

## Actualizare
1. Modifică datele din secțiunea `DATE PERSONALE` din `build.py`.
2. (Opțional) pune poza ta ca `source/portrait.jpg` (pătrată, ~800×800).
3. Rulează `python build.py` – site-ul se generează în `docs/`.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /docs → Save.
